Step 1: Introduction to Git
What is Git?

"Git is a Version Control System. It is used to track and manage changes in our source code. It helps developers maintain different versions of a project and restore previous versions whenever needed."

Example:

Suppose we are developing a Python project. Every time we modify the code, Git helps us track those changes.



Step 2: Introduction to GitHub
What is GitHub?

"GitHub is an online platform used to store and manage Git repositories. It helps developers share their code and collaborate with team members."

Difference:
- Git tracks changes in our local project.
- GitHub stores our project online and helps us collaborate with others.
Step 3: Install Git
How to install Git:
1. Open the official website: Git Download.
2. Select Windows.
3. Download the Git installer.
4. Open the downloaded installer.
5. Follow the installation instructions.
6. Complete the installation.
How to verify installation:

Open VS Code terminal and execute:
git --version


If the Git version appears, installation is successful.

Step 4: Configure Git
After installation, we need to configure our username and email address.

Configure username:
git config --global user.name "Your Name"


Configure email:
git config --global user.email "yourmail@gmail.com"


Check configuration:
git config --list
